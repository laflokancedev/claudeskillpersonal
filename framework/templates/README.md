# templates/

Gabarits pour étendre le framework de façon cohérente.

| Fichier | Sert à créer |
|---------|--------------|
| `SKILL.template.md` | Un nouveau skill expert (8 sections obligatoires) |
| `agent.template.md` | Un nouvel agent (rare — le cœur est stable) |
| `command.template.md` | Une nouvelle slash command |
| `ADR.template.md` | Un Architecture Decision Record |

Copier le gabarit, remplir, respecter `docs/CONVENTIONS.md`. Pour un skill, suivre en
plus `docs/ADDING-A-SKILL.md`.
